# IntelliWealth MVP (mvp-intelliwealth-output1)

A comprehensive financial planning tool that helps users track their income, expenses, investments, loans, goals, and insurance.

## Features

- **Auto-calculating Summary Dashboard**: Real-time calculations for:
  - Gross Monthly Income
  - Total Monthly Expenses
  - Monthly Debt Payments
  - Savings Rate
  - Net Monthly/Annual Surplus
  - Debt-to-Income Ratio
  - Estimated Net Worth

- **10 Comprehensive Sections**:
  1. General Questions (age, retirement planning, inflation)
  2. Home Rent Expenses
  3. Home EMI Expenses
  4. Children's University Expenses
  5. Income Details (salary, bonus, rental, business, investments)
  6. Expenses Details (rent, school, household, vacation, insurance)
  7. Investments (mutual funds, stocks, bonds, real estate, gold)
  8. Loans (home, car, personal, education, business)
  9. Goals (education, marriage, retirement, vacation, home, car)
  10. Insurances (life and health coverage)

- **Dark/Light Theme Toggle**
- **Responsive Design**

## Deployment

This application is deployed as a static website via GitHub Pages.

**Live URL**: `https://github-code542.github.io/hello-world/`

To enable GitHub Pages:
1. Go to repository Settings > Pages
2. Under "Source", select the branch `claude/deploy-intelliwealth-mvp-lfGxJ`
3. Select "/ (root)" as the folder
4. Click Save

## Local Development

Simply open `index.html` in any modern web browser.
