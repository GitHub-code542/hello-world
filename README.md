# IntelliWealth Enhanced - Neo-Financial Luxury Edition

## 🎨 Design Philosophy

**Neo-Financial Luxury** - A sophisticated financial planning app combining premium fintech elegance with engaging gamification mechanics.

### Color Palette
- **Navy/Indigo Base**: Deep, trustworthy foundation (#0a0e27, #1f2847)
- **Gold Accents**: Luxury highlights (#d4af37, #f4d47d)
- **Emerald**: Success & growth indicators (#10b981, #059669)
- **Ruby**: Expense tracking (#ef4444)
- **Pearl**: Clean content (#f8fafc)

### Typography
- **Display**: Playfair Display (elegant serif for titles & emphasis)
- **Body**: Outfit (modern sans-serif for clarity & readability)

## ✨ Key Features

### 💰 Gamification System
- **Financial Score** (0-1000): Dynamic score based on savings behavior
- **Level System** (1-20): Progress through levels as you improve
- **XP Progress Bar**: Visual feedback with gradient animations
- **Achievement Badges**: Unlock rewards for milestones
  - 🎯 Saver: Positive savings rate
  - 💰 High Saver: 40%+ savings rate (with confetti celebration!)
- **Streak Counter**: Track daily engagement

### 📊 All 4 Pages Fully Functional

#### Page 1: Income & Expenses
- Interactive drag sliders with shimmer effects
- Real-time calculation of savings rate
- Animated vault with particle effects
- Income vs expense tracking with visual feedback

#### Page 2: Balance Sheet
- Interactive balance scale that tilts based on net worth
- Click-to-add assets & liabilities
- Editable values with live updates
- Visual distinction between assets (green) and liabilities (red)
- Golden fulcrum with dramatic shadows

#### Page 3: Life Goals Timeline
- Drag & drop life milestones onto timeline
- Customizable age and budget for each goal
- Gender toggle for character representation
- Curved timeline with age markers
- Editable and deletable goals

#### Page 4: FIRE Analysis
- Auto-populated from previous pages
- **Scenario Analysis Tab**:
  - Job gap simulations
  - Income loss scenarios
  - Medical expenses planning
  - Caregiving breaks
- **Stress Test Tab**:
  - Market crash simulations
  - ROI/Inflation adjustments
  - Income/expense growth rates
  - Maximum working age limits
- Real-time FIRE age calculations
- Status indicators (On Track / Needs Adjustment)

### 🎭 Visual Effects
- **Glassmorphism**: Frosted glass panels with backdrop blur
- **Particle System**: Floating emerald particles from vault
- **Confetti Celebrations**: Multi-color confetti on achievements
- **Glow Animations**: Pulsing effects on key metrics
- **Smooth Transitions**: Page slides, hover effects, transforms
- **Grain Texture**: Subtle background texture overlay
- **Shimmer Effects**: Animated gradients on sliders

### 💾 Data Persistence
- **Auto-save**: Changes saved 1 second after modifications
- **LocalStorage**: All data persists across sessions
- **Export/Import**: JSON backup & restore functionality
- **Clear Data**: Option to reset everything

## 🚀 How to Use

1. **Open**: `index-enhanced.html` in any modern browser
2. **Navigate**: Use the step indicators or navigation buttons
3. **Interact**:
   - Drag sliders to adjust income/expenses
   - Click assets/liabilities to add them
   - Drag goals onto the timeline
   - Adjust FIRE scenario sliders
4. **Save**: Auto-saves after changes, or click SAVE buttons
5. **Export**: Use 📤 Export to backup your data
