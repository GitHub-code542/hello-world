# IntelliWealth - Financial Goal Planning

A sophisticated financial planning web application combining premium fintech elegance with engaging gamification mechanics.

## 🎨 Design Philosophy

**Neo-Financial Luxury** - Deep, trustworthy color palette with gold accents, emerald success indicators, and clean pearl content areas.

## ✨ Key Features

### 📊 All 4 Pages Fully Functional

1. **Income & Expenses** - Interactive sliders, real-time savings calculations, animated vault with particle effects
2. **Balance Sheet** - Interactive balance scale, click-to-add assets & liabilities, live net worth updates
3. **Life Goals Timeline** - Drag & drop milestones, inline goal editor, curved timeline with age markers
4. **FIRE Analysis** - Scenario analysis, stress testing, real-time FIRE age calculations

### 💰 Gamification System
- Financial Score (0-1000) based on savings behavior
- Level System (1-20) with XP progress bar
- Achievement Badges with confetti celebrations
- Streak Counter for daily engagement

### 🎭 Visual Effects
- Glassmorphism with backdrop blur
- Particle system and confetti celebrations
- Glow animations and smooth transitions
- Responsive design for all screen sizes

### 💾 Data Persistence
- Auto-save to localStorage
- Export/Import JSON backup functionality
- Clear data option

## 🚀 Quick Start

1. Open `index.html` in any modern browser
2. Navigate using the sidebar or step indicators
3. Interact with sliders, add goals, adjust scenarios
4. Data auto-saves after changes
